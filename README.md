# Yuvraj Dhariwal Portfolio

Premium AI Automation Engineer portfolio built with Next.js, TypeScript, Framer Motion and Lucide.

## Run locally

`npm install` then `npm run dev`

## Build

`npm run build`

## Email configuration

The contact email is configured in `app/page.tsx` and `app/work/[slug]/page.tsx`. No secrets are needed.

## Deploy

Push this repository to GitHub and import it in Vercel. Vercel detects Next.js automatically; no extra configuration is required.
